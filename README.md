# Just (Video) Player Enhanced

This repository is a modified fork of [Just (Video) Player](https://github.com/moneytoo/Player) with Dolby Vision processing additions, rest all features are identical.

## Added Features

- Dolby Vision Profile 7 to Profile 8.1 conversion (FEL is discarded, if present)

- HDR10+ is stripped from DV HDR10+

## Usage & Documentation

Because the core application remains unchanged, all original commands, installation steps, and
configurations still apply.
